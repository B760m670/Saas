# Gloria FX — движок эффектов сайта

WebGL-сцены для кабинета и витрины: шейдеры, блум, частицы. Canvas 2D
рисует линии и пятна, а здесь каждый пиксель света считает видеокарта —
отсюда «живая» энергия, свечение, атмосфера.

| Файл | Что |
|---|---|
| `src/energy.js` | сцена «Энергия»: планета, столбы энергии, дуга срока |
| `tex/day.jpg` | Земля днём, 2048×1024 (NASA Blue Marble) |
| `tex/night.jpg` | огни городов ночью, 4096×2048 (NASA Black Marble) |
| `tex/water.jpg` | маска воды для блика солнца, 1024×512 |
| `src/index.js` | точка входа: `window.GloriaFX = { mountEnergy, supported }` |
| `energy.js` | собранный файл (three.js + сцены), его и грузит страница |
| `build.sh` | сборка `energy.js` из `src/` |

## Как подключено

Кабинет (`site/index.html`) загружает `fx/energy.js` в простое, через
2 с после открытия, и заранее компилирует шейдеры: по нажатию «Продлить»
сцена готова сразу. Сам кабинет от движка не тяжелеет (~130 КБ по сети
плюс ~770 КБ текстур, один раз, дальше из кэша). Без WebGL экран продления
остаётся тёмным, с датой и кнопкой оплаты.

## Планета

- день: текстура Blue Marble, освещение от «солнца», блик на воде;
- терминатор: узкая тёплая полоса заката между днём и ночью;
- ночь: огни городов из Black Marble (оранжевые, отделены от лунного
  фона по цвету) поверх тусклой подсветки суши;
- облака: процедурный шум (fbm) на отдельной сфере, плывут чуть быстрее
  поверхности;
- атмосфера: голубая со стороны солнца, к терминатору — оранжевая;
- столбы энергии подсвечивают поверхность вокруг своего основания.

Текстуры взяты из npm-пакета `three-globe@2.41.12` (MIT); оригиналы
NASA — общественное достояние. Имена текстур не версионируются, а Caddy
кэширует `/fx/*` на год: при замене текстуры меняйте имя файла.

## Нагрузка

- плотность пикселей не выше 1,75;
- блум считается в половинном разрешении;
- 40 медленных кадров подряд (дольше ~28 мс) — движок сам выключает блум
  и половину искр;
- `prefers-reduced-motion` — один неподвижный кадр;
- анимация идёт только пока экран открыт.

## Сборка

```sh
cd site/fx
npm i --no-save three@0.169.0 esbuild@0.24.0
sh build.sh
```
