# Точка выхода на Cloudflare Workers

Бесплатный тариф, регистрация по почте, **карта не нужна**. Это и есть
ответ на главное препятствие проекта: где взять узел за границей, не
арендуя его.

## Что нужно

Аккаунт Cloudflare и Node.js. Больше ничего.

## Порядок

```bash
cd clients/worker

# 1. Придумать секрет и идентификатор пользователя.
node -e '
  const b = crypto.getRandomValues(new Uint8Array(32));
  const b64 = Buffer.from(b).toString("base64url");
  console.log("секрет:", b64);
  console.log("uuid:  ", crypto.randomUUID());
'

# 2. Развернуть.
npx wrangler deploy

# 3. Положить секреты (значения из шага 1).
npx wrangler secret put ATLAS_SECRET
npx wrangler secret put ATLAS_UUID
```

`wrangler deploy` напечатает адрес вида
`https://atlas-edge.ваш-поддомен.workers.dev`.

## Два режима

| Путь | Кто говорит | Что даёт |
|---|---|---|
| `/` | Happ, Hiddify, v2rayNG — любой клиент | обычный VLESS поверх WebSocket |
| `/e` | только наш клиент | плюс сквозной канал: посредник между телефоном и Cloudflare ничего не получит |

Выбор по пути, а не угадыванием по первым байтам: угадывать — значит
однажды принять чужое приветствие за своё.

Обычный режим слабее по скрытности: она держится только на TLS самого
Cloudflare. Зато он работает с тем, что человек уже поставил из App
Store, — а приложение, которого нет, не защищает никого.

## Ключ доступа

```
vless://UUID@atlas-edge.ваш-поддомен.workers.dev:443?type=ws&security=tls&path=/&host=atlas-edge.ваш-поддомен.workers.dev&fp=chrome#atlas
```

Вставляется как есть в Happ, Hiddify или v2rayNG — они дадут системный
VPN на всём устройстве, включая приложения и сотовую связь.

Для нашего клиента путь меняется на `/e`, и добавляется `&edge=СЕКРЕТ`:
это наше расширение, чужие клиенты его не понимают.

## Что здесь честно сказать

**Cloudflare видит ваш трафик.** Край обязан знать, куда соединяться,
иначе он не соединится. Сквозной канал закрывает посредника между
телефоном и Cloudflare — то есть ТСПУ, — но не саму площадку. Обещать
приватность от Cloudflare было бы враньём.

**Условия использования — серая зона.** Бесплатный тариф не задуман под
проксирование. Заводите отдельный аккаунт, потеря которого ничего не
рушит.

**Скорость ниже, чем у своей машины.** HTTP-обрамление, ограничения на
длительность соединения, лимиты бесплатного тарифа.

## Согласие двух реализаций

`src/edge.js` описывает тот же протокол, что `core/atlas-transport/src/edge.rs`.
Два описания одного протокола расходятся всегда, поэтому согласие
проверяется настоящим прогоном: `core/atlas-transport/tests/interop.rs`
поднимает эту сторону узлом и сверяет байты в обе стороны.

Правка здесь без правки там уронит сборку. Так и задумано.
