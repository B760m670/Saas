# Копии баз

Всё остальное восстанавливается: бот собирается из репозитория, панель
переустанавливается, сервер поднимается новый за час. Не восстанавливается
одно — кто у вас купил подписку и до какого числа. Этого нет больше нигде.

Без копии потеря базы выглядит так: люди, которые заплатили, остаются без
доступа, доказать оплату они не могут, и вы тоже. Дальше — возвраты всем,
кто попросит, включая тех, кто не платил.

## Поставить

Один раз, на машине с панелью:

```bash
install -m 700 deploy/backup/gloria-backup.sh /usr/local/bin/gloria-backup.sh
install -m 644 deploy/systemd/gloria-backup.service /etc/systemd/system/
install -m 644 deploy/systemd/gloria-backup.timer   /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now gloria-backup.timer
```

Сразу же — **проверить, а не поверить**:

```bash
systemctl start gloria-backup.service
journalctl -u gloria-backup -n 20 --no-pager
ls -l /var/backups/gloria/
```

В журнале должны быть две строки `снято:` — по одной на базу, — и оба
файла должны лежать на месте, весом больше килобайта. Расписание:

```bash
systemctl list-timers gloria-backup
```

## Что снимается

Две базы, обе из контейнера панели: `postgres` — панельная, `gloria` —
наша. Имя панельной в разных сборках отличается; уточнить можно так:

```bash
docker exec remnawave-db psql -U postgres -l
```

Если оно другое — задайте перед установкой:

```bash
GLORIA_BACKUP_DATABASES="имя_панельной gloria"
```

Хранятся четырнадцать дней. Старое удаляется **только после удачного
снятия сегодняшнего**: иначе неделя тихих отказов съела бы все копии, и
последнюю удалили бы ровно в тот день, когда она понадобилась.

Дамп пишется во временный файл и переименовывается только после проверки
архива на целостность и непустоту. Прерванная копия не должна выглядеть
готовой — именно такую и находят в момент, когда она нужна.

## Восстановить

Проверять надо не наличие файла, а восстановление из него. Копия, которую
ни разу не разворачивали, — это предположение, а не копия.

```bash
gunzip -c /var/backups/gloria/gloria-ГГГГММДД-ЧЧММСС.sql.gz \
  | docker exec -i remnawave-db psql -U postgres -d gloria_check
```

Разворачивать в **отдельную** базу (`createdb gloria_check`), а не поверх
рабочей. Проверить, что люди на месте:

```sql
SELECT count(*), max(expires_at) FROM users;
```

## Копия рядом с базой — половина дела

Она спасает от неудачной миграции, ошибочного запроса и порчи данных. От
потери самой машины — нет: файлы лежат на том же диске.

Самое простое, что не требует настройки на серверах, — забирать себе:

```bash
scp root@ПАНЕЛЬ:/var/backups/gloria/'*.sql.gz' ~/backup/
```

Складывать к стороннему поставщику можно, но дамп содержит идентификаторы
Telegram всех покупателей — только в зашифрованном виде.
